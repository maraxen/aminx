# Ecosystem backlog DAG (261001 spec set)

## 1. Overview and spec index

This plan merges the backlogs of the six 261001 specs into one dependency graph. It covers renaming the
MPNN package from `aminx` to `molxmpnn` so `aminx` can become the hub (D2), moving ProteinEBM into its own
project (D3, praxia debt #2369), unifying the two spec systems (D4), the xtrax model contract, the static hub,
and the shared pipeline editor. Nothing here runs yet (D7). Work order is set only by `depends_on`, and every
item is one PR or one recorded decision. There are **231 items** (113 S, 102 M, 16 L) and **553 edges**.
**61 items are `user_decision = true`**: they record a choice of yours, or a user action such as publishing,
creating a repo, deleting something or approving GPU time. The graph assumes **rename-first (R)**. That is the
shared recommendation of S1 Q10, S2 Q7 and S3 Q4. You decide it once, at S3-01 (OQ-01 below). If you choose
E instead, the edges listed in S3 section 2 flip.

Everything an item depends on comes from the `toml` block of its own spec. The workflow passed in an
authoritative item list, and code checked that list against the specs' blocks (section 7): they match on
every id, repo, size, `user_decision` and `depends_on`.
